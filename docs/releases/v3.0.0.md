# ries-rs v3.0.0 — draft, unpublished

This major release corrects search coverage and stop ordering, makes unavailable
numerical verification explicit, and adds independent qualification tools. No
version DOI or publication date is claimed by this draft.

## Migration

- `ExpressionConstraintOptions` adds `user_function_constraints`. Rust callers
  with exhaustive struct literals must supply it or use `..Default::default()`;
  use `UserFunctionConstraints::from_function` when restrictions inspect bodies.
- `SearchStats` adds `candidate_window_histogram`; exhaustive literals need the
  new field or `..Default::default()`.
- Searches preserve structurally distinct LHS expressions by default. Results,
  first equations, roots, latency, and memory can change. `--lhs-value-dedup`
  opts materialized searches into the former heuristic; streaming preserves LHS.
- Stop searches put the simplest qualifying equation first, followed by ranked
  results within its complexity bound. CLI deterministic/turbo postprocessing
  preserves that winner.
- Unavailable high-precision checks return `is_verified = false` and status
  `Unavailable`. Consumers should use the three-state status.
- Function definitions containing nested user-function aliases now fail parsing.

- Match-all-digits rejects decimal rounding beyond the requested last-place
  tolerance; nonzero decimals that underflow to zero are rejected. This is shared
  by CLI and WASM text targets.
- Explicit verification requests fail when unavailable unless
  `--allow-unverified` is supplied; fallback JSON states unavailable.
- Adaptive JSON/manifests report actual final bounds separately from requested
  bounds. Incompatible streaming/turbo/memory-hint combinations fail explicitly.
- Python's native build target is renamed internally to avoid Cargo artifact
  collisions; `import ries_rs` is unchanged.

- Decimal validation precedes target-consuming special modes, including PSLQ.
- Manifests add `SearchConfigInfo::target_literal` and replay the original decimal
  spelling. Exhaustive Rust struct literals must supply this optional field.
- Replay defaults to identical f64 root/error bits; tolerant comparison requires
  an explicit comparison mode and absolute tolerance.
- Polynomial certificates preflight arithmetic against a 4096-bit budget.

## Added and hardened

- `--strict-config` rejects invalid or ignored custom configuration before search;
  manifests preserve it. CLI JSON preserves `target_literal` separately from f64.
- Candidate-window histograms expose derivative-driven matching outliers.
- Fixed-corpus cross-matcher qualification records ordered equations, roots,
  missing candidates, effective matcher, wall time, and peak RSS. A seeded tiny
  grammar oracle varies weights, symbol restrictions, and budgets independently.
- A separate historical differential compares known-answer polynomial identities
  and independently bounded roots. The existing accuracy smoke test remains.
- Browser LaTeX groups right-associated exponent chains correctly instead of
  producing double-superscript errors.
- Built-browser CI includes mobile and static-site search tests. Tailwind styles
  compile to static CSS from a committed npm lockfile.
- Every tagged release reruns the full reusable CI workflow at that exact commit
  before artifact builds and publication can begin.

## Experimental evidence tools

`algebraic_certificate.py` emits and checks rational root certificates for a
restricted degree-at-most-two polynomial grammar. Unsupported cases explicitly
return unavailable. This is independent exact arithmetic checking, not a Lean
kernel proof or proof that a decimal equals an intended irrational constant.
`run_bounded.py` adds Linux-enforced address-space limits and a wall-time
supervisor; `--max-memory` itself remains a strategy hint.

See [qualification documentation](../QUALIFICATION.md) for reproduction commands,
trust boundaries, and resource semantics. Local baseline artifacts describe an
uncommitted candidate, not a published or universally qualified release. The
release CI must qualify the final tagged commit on supported platforms.
