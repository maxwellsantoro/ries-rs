# ries-rs v2.0.3

Patch release correcting solved-for-x equation display, exact-match labeling,
and underflow handling.

## Bug fixes

- Solved equations now use the real branch nearest the reported root. A match
  such as `sin(πx) = 1` near 2.5 prints as 2.5, not the principal value 0.5.
  Cosine, tangent, squares, and other even roots make the same choice. Odd
  powers keep their single real root.
- Large period shifts work. Any finite integer, including magnitudes past
  `2^63`, is a valid shift. If that branch cannot be represented, the solved
  form is omitted.
- Trig parity at large magnitudes is fixed. `sinpi`, `cospi`, and `tanpi` no
  longer take parity from a saturating integer cast. Every finite value at
  magnitude `2^52` or above is an integer, and every finite value at `2^53`
  or above is even, so `tanpi` of `2^62` is 0 rather than a pole.
- An exact match now requires both sides to agree at the typed target, with
  the solved `x` within a few ulps of that target. A Newton step onto a
  different nearby root is not labeled exact.
- Flushed `x` terms are skipped at any magnitude. When the `x` contribution
  has disappeared into a constant, and a probe shows the expression is not a
  true identity, that candidate is left out. Real identities such as
  `x * (1/x) = 1` stay.
- Newton residual gating keeps a refined root only when the two sides are
  actually close. A tiny step that leaves a large residual is rejected. Steep
  roots whose relative residual is still small are kept.

## Changed

- Coverage now runs on LLVM. The coverage job no longer uses tarpaulin's
  ptrace engine, which crashed while dropping an expression after a passing
  manifest test.

## Compatibility

- No public API changes.

## Distribution notes

- CLI archives are provided for Linux x86_64, macOS x86_64 and arm64, and
  Windows x86_64.
- The release includes browser, Node.js, and bundler WASM packages.
- PyPI artifacts include stable-ABI wheels and a source distribution.
- No Zenodo version DOI is recorded until the v2.0.3 archive has completed. The
  project concept DOI remains `10.5281/zenodo.19101924`.
